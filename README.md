# 🚢 Titanic Survival Prediction using Gradient Boosting

This project applies **Gradient Boosting Classifier (GBM)** on the Titanic dataset to predict passenger survival.

## 📂 Dataset
- `train.csv` contains passenger details:
  - Pclass (Ticket class)
  - Sex (Gender)
  - Age
  - SibSp (Siblings/Spouses aboard)
  - Parch (Parents/Children aboard)
  - Fare (Ticket Fare)
  - Embarked (Port of Embarkation)

## 🚀 Features
- Handles missing values (Age, Fare, Embarked)
- Encodes categorical variables (Sex, Embarked)
- Splits data into training (80%) & testing (20%)
- Trains **Gradient Boosting Classifier**
- Evaluates performance using Accuracy, Precision, Recall, F1-score

## 📊 Output
- Accuracy score
- Precision, Recall, F1-score
- Classification Report

## 🛠️ Tech Stack
- Python
- Pandas
- scikit-learn

## 📌 Use Cases
- Learning supervised ML models
- Working with real-world Titanic dataset
